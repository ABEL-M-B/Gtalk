# Gtalk

Gtalk is a lightweight web chat interface built with HTML, CSS and JavaScript.

This repository contains the static frontend for the project (no backend included).

## Features

- Simple, responsive HTML/CSS UI
- Client-side JavaScript for message handling
- Easy to run locally as a static site

## Quick start

1. Clone the repository:

   git clone https://github.com/ABEL-M-B/Gtalk.git

2. Open index.html in your browser, or serve the folder with a static server:

   npx http-server .

   or with Python 3:

   python -m http.server 8000

3. Navigate to http://localhost:8080 (or http://localhost:8000) to see the app.

## Development

- Files are primarily HTML, CSS, and JavaScript in the repository root (or directories).
- Edit the files and refresh the browser to see changes.
